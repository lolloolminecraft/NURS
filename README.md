# Nurs-Mode (NM)

Личное приложение-фундамент для iPhone. Исходники SwiftUI: ios/NursMode/NursModeApp.swift.

Главный экран показывает проекты. PS4 14.00 — первый встроенный раздел. Проверку источников каждый час выполняет задача ChatGPT «NM — PS4 14.00», которая при наличии данных обновляет docs/status.json в этом репозитории. Приложение само не ищет джейлбрейк и не объявляет видео релизом.

Новые веб-проекты можно добавить в docs/projects.json с kind="web", ссылкой https и уникальным id — они появятся на главном экране при следующем запуске без обновления IPA.

Статус хранится в docs/status.json:
- state: waiting | progress | exploit | released
- status_text: короткое сообщение для значимого статуса
- summary: подтвержденное описание
- status_changed_at: время последнего значимого перехода в UTC
- last_checked_at: реальное время последней успешной проверки источников ChatGPT в UTC
- checked_sources: массив {name,url} реальных проверенных источников
- release: данные публичного релиза только при state=released.

GitHub-репозиторий должен оставаться публичным, чтобы установленная версия получала JSON напрямую по HTTPS, не раскрывая токены.

Сборка: подключить GitHub к Codemagic, выбрать codemagic.yaml и workflow «Nurs-Mode IPA for Sideloadly», скачать Nurs-Mode.ipa. Это неподписанный IPA. Sideloadly может подписать его личной учетной записью Apple; переустановка/переподпись зависит от её срока.

ВАЖНО: Локальные уведомления работают только после того, как приложение само увидело изменение. Настоящие серверные push при закрытом приложении требуют APNs и соответствующих Apple entitlements/учетной записи разработчика; они НЕ реализованы в этом бесплатном IPA. Для своевременных уведомлений без APNs используйте уведомления от ежечасной задачи ChatGPT при подтверждённой значимой новости, если они включены в ChatGPT. Установка IPA не может обойти ограничения APNs.


## Бесплатная проверка в фоне через iPhone «Команды»

В NM добавлено системное действие **«Проверить PS4 14.00»** из App Intents. Оно проверяет status.json, сохраняет значимые изменения и создаёт локальное уведомление от Nurs-Mode, если действительно изменилось состояние. Поиск первоисточников выполняет ежечасная задача ChatGPT, а не приложение.

Настройка на iPhone после установки нового Nurs-Mode.ipa:
1. Открой NM → Настройки → **Разрешить локальные уведомления**. Кнопкой **Проверить уведомление** убедись, что баннер виден.
2. Открой системные **Команды** → **+** → **Добавить действие** → найди **Nurs-Mode** → **Проверить PS4 14.00**. Нажми ▶ для первого теста. В NM → Настройки появится **Последний фоновый запуск**.
3. В **Команды → Автоматизация → + → Время суток** выбери удобное время, **Ежедневно**, **Запускать немедленно**, затем действие NM «Проверить PS4 14.00» (либо команду, созданную на шаге 2). Убедись, что выбрана автоматизация без подтверждения.
4. Если нужны проверки чаще раза в день, добавь расписания на другие часы. У стандартного триггера «Время суток» нет универсальной настройки «каждый час».
5. В iOS Настройки → Основные → Обновление контента разреши фоновое обновление для NM. По возможности отключи режим энергосбережения.

Раздел «Последний фоновый запуск» — реальное время успешной проверки NM. Раздел PS4 «Последняя проверка ChatGPT» — время работы внешней задачи ChatGPT. Это разные проверки.

**Важно:** Shortcuts и BGAppRefresh не обеспечивают постоянную работу в фоне и не гарантируют запуск при заблокированном iPhone, в любой час или немедленное уведомление. Для надёжных мгновенных push нужны APNs и соответствующая подпись Apple. **VPN, геолокация и беззвучное аудио не используются.**


## NM Live — обновления интерфейса без нового IPA

**По умолчанию NM открывает Live-интерфейс** из docs/nm-live.html. Оболочка SwiftUI в ios/NursMode/NMLiveHome.swift получает HTML через публичный GitHub HTTPS при запуске и возвращении из фона, сохраняет последнюю успешную копию, использует её при отсутствии интернета. Веб-интерфейс запрашивает docs/projects.json и docs/status.json (с обновлением примерно раз в пять минут пока экран открыт). На нативном экране настроек можно отключить NM Live и вернуться к встроенному интерфейсу.

Чтобы изменить экран без нового IPA: обновить docs/nm-live.html в GitHub и затем закрыть/открыть NM или снова сделать его активным. Чтобы добавить проект, обновить docs/projects.json: новый проект kind=web с https URL появится на главном экране без переподписи.

Этот способ позволяет менять HTML/CSS/JS и данные, но **не исполняет новые нативные Swift-библиотеки**. Новые системные возможности iOS, App Intents, APNs, фоновые режимы, Bundle ID и иконка требуют новой подписанной сборки. Бесплатная подпись Sideloadly сама по себе действует ограниченное время. Не обещать «любое автообновление без IPA».

Переход к нативной карточке PS4 и настройкам доступен из NM Live. При приходе локального уведомления оно открывает нативную карточку PS4.
