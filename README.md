# Опора

Личное iPhone-приложение. Ежечасный поиск PS4 14.00 выполняется задачей ChatGPT, а `docs/status.json` сохраняет подтверждённые сведения. SwiftUI-приложение находится в `ios/`. Сборка неподписанного IPA для Sideloadly запускается через GitHub Actions → Opora iPhone IPA.

Пока репозиторий приватный, приложение не может прочитать `docs/status.json` напрямую: нужен публичный HTTPS-источник. Для настоящих push-уведомлений при закрытом приложении нужна отдельная инфраструктура APNs и подходящая подпись Apple.
