# Nurs-Mode (NM) — каноническое описание проекта

**Название приложения:** Nurs-Mode, сокращённо NM. НЕ «Опора»: этим словом пользователь называл фундамент для множества проектов, а не название.
**Хранилище:** публичный GitHub-репозиторий https://github.com/lolloolminecraft/NURS, ветка main.
**Сборка IPA:** файл codemagic.yaml в корне, workflow «Nurs-Mode IPA for Sideloadly», артефакт Nurs-Mode.ipa — неподписанный, пользователь сам устанавливает через Sideloadly. Сборка/установка должна быть проверена на реальном устройстве; не выдумывать ссылку на готовый IPA.
**Позиционирование:** личная платформа / контейнер для экспериментов и разных проектов. PS4 14.00 — первый проект, не назначение всего приложения.

## Архитектура

- SwiftUI нативная оболочка: ios/NursMode/NursModeApp.swift.
- **NM Live** обновляемый удалённо интерфейс: ios/NursMode/NMLiveHome.swift + docs/nm-live.html.
- NMRoot по умолчанию открывает режим NM Live. HTML скачивается из публичного GitHub при открытии/возвращении в приложение, обновляется только если данные действительны и сохраняется офлайн. Во вкладке настроек есть переключатель «NM Live — обновлять интерфейс без IPA».
- Список проектов: docs/projects.json. kind=ps4 встроен; kind=web + https URL добавляет новые веб-проекты, отображаемые без нового IPA.
- Статус PS4: docs/status.json. Поля state, status_text, summary, significance, last_checked_at, status_changed_at, checked_sources и release. last_checked_at меняется при успешной проверке, status_changed_at меняется только при достоверном **важном** изменении. Значения: waiting, progress, exploit, released. release заполняется только для подтверждённой общедоступной работающей цепочки именно для FW 14.00, реальные source_url, download_url, instructions, video_url (только реальное). Внимание: ролик, WebKit PoC или поддержка 13.52 не считаются джейлбрейком 14.00.
- Ежечасный поиск делает **встроенная задача ChatGPT «NM — PS4 14.00»**, а не независимые скрипты, WhatsApp-бот или клиент NM. При событии задача обновляет GitHub.
- Локальная история статусов и локальные уведомления: NMStatusCache, NMBackgroundMonitor в NursModeApp.swift. Фоновая задача BGAppRefreshTask зависит от решений iOS.
- Действие приложения «Команды» (App Intents): ios/NursMode/NMAppIntents.swift — «Проверить PS4 14.00». Может обновить состояние, локально уведомить при значимом переходе и запомнить время фактической проверки. Расписания «Команд» создаёт пользователь вручную.
- Встроенный видеоплеер: Native YouTube WKWebView / AVPlayer; Live HTML YouTube iframe/video.

## Что уже возможно обновлять без нового IPA

1. Интерфейс HTML/CSS/JS docs/nm-live.html и расположение карточек.
2. Новые веб-проекты в docs/projects.json и их содержимое по HTTPS.
3. Статусы, тексты, первоисточники, ссылки скачивания и видео docs/status.json.

**Чего нельзя надёжно делать без нового подписанного IPA:** новые iOS entitlements и фоновые разрешения, новый Swift или App Intents-код, изменение самой нативной архитектуры, установка новых нативных библиотек и смена значка/Bundle ID; переподпись Sideloadly обычно нужна после семи дней с бесплатным Apple ID. Невозможно произвольно обновлять нативный код поверх IPA, как веб-страницу.

## Ограничения уведомлений

- Отдельный платный Apple Developer сейчас не подтверждён.
- Настоящие APNs push **не настроены**. Нет гарантий уведомления при закрытом приложении; фоновый refresh и Shortcuts вызываются системой по её правилам.
- Кнопка теста в настройках проверяет только создание локального уведомления, не подделывает релиз.
- Не обещать 24/7-работу в фоне. Не применять VPN, геолокацию, беззвучное аудио как искусственное удержание процесса.

## Обязательная процедура будущих изменений

Если пользователь просит «вспомни проект Нурс-Мод / Nurs-Mode / NM» — начать с этого файла, README, ios/project.yml, ios/NursMode, docs, codemagic.yaml и подключённого GitHub. Уточнить требование только если оно действительно неочевидно. Вносить точечные правки через GitHub, проверять взаимосвязанные файлы, не стирать другие проекты/настройки. Разделять OTA-изменения (HTML/JSON) и изменения требующие IPA (Swift). Проверять синтаксис и сборку, если доступен macOS runner; не утверждать компиляцию без отчёта. Давать краткий отчёт о том, что реально выполнено, и одну понятную следующую операцию, если нужна.

Слова пользователя: личная лаборатория, Nurs-Mode (NM), фундамент для разных идей, UI и дополнительные проекты обновлять через GitHub без загрузки нового IPA; мониторинг PS4 14.00 — только средствами ChatGPT.
